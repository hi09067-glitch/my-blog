# Spring Boot 개발 노트

## 1. REST API 작성

```java
@RestController
@RequestMapping("/api/posts")
public class PostController {
    @GetMapping
    public String getPosts() {
        return "Hello Spring Boot";
    }
}
```

## 2. 기억할 내용

- Controller는 요청을 처리한다.
- Service는 비즈니스 로직을 담당한다.
- Repository 또는 Mapper는 데이터를 조회한다.
